Founder feedback after the release: the landing's design and layout are still not there; on a phone it is "horrible" and low quality. Reference offered: github.com/anomalyco/rune.

What Rune is: a native Rust UI framework, not a web library. Reusable for this site is its docs site (`site/`, MIT), built on Anomaly's "Workbench" system: few type sizes on a 4 px grid, one neutral at four strengths, hairlines, two radii, one accent, diagrams in plain HTML that stack on a phone, an index-row list, nothing moving on first paint. ## Eighth pass: smooth scrolling (2026-11-15)

The founder tested direction A in Chrome and reported two things: the movement was not fluid, and the room itself did not convince. Reference given for style: motionsites.ai (hero built on one cinematic generated video, short headline, smooth motion).

- [x] Scroll jank, root cause: `motion.ts` wrote `--cy-scroll` on the `<html>` element on every scroll frame, which made the browser recompute the style of every element on the page each frame. The progress bar now gets its transform directly. This defect is also in the version in production (commit `656c4ce`).
- [x] Removed the page-wide effects that cost the most: the full-screen light that followed the pointer, the film grain animation, blur on reveals and on word-by-word headlines, and the endless slow zoom on the hero picture.
